# Article fonts

These fonts are bundled for the article-detail font picker. They are open-font
licensed and sourced from the following projects:

- Charis SIL — <https://software.sil.org/charis/>
- IBM Plex Serif — <https://github.com/IBM/plex>
- Source Serif 4 — <https://github.com/adobe-fonts/source-serif>
- Literata — <https://github.com/googlefonts/literata>
- Noto Serif — <https://github.com/notofonts/latin-greek-cyrillic>

See each project for its license and copyright notice.
